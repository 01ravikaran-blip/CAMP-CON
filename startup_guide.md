# Easy Start Guide 🚀

I have fixed the final code lints and created a one-click startup script for you.

## How to Start Everything

1. Open your terminal in `smart-campus-app`.
2. Run this command:
   ```powershell
   .\start-all.ps1
   ```

### What it does
It opens separate terminal windows for all 8 parts of your stack:

- **Frontend** (Port 3000)
- **Auth Service** (Port 3001)
- **Verification Service** (Port 3002)
- **Social/Media Service** (Port 3003)
- **Marketplace** (Port 3004)
- **Events** (Port 3005)
- **Chat** (Port 3006)
- **Wallet** (Port 3007)

Once the windows open, just go to **http://localhost:3000** in your browser.

The App is Ready. Enjoy your Smart Campus!
